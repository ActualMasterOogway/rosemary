Rosemary Steam compatibility tool
=================================

To install: move this directory into Steam's compatibilitytools.d, then restart Steam:

    ~/.steam/root/compatibilitytools.d/                    (most installs)
    ~/.local/share/Steam/compatibilitytools.d/             (some installs)
    ~/.var/app/com.valvesoftware.Steam/.local/share/Steam/compatibilitytools.d/   (Flatpak)

Then pick "Rosemary (macOS)" under a game's Properties > Compatibility.
It applies to games that have a macOS build.

Everything Rosemary needs is in this directory. Library sources are in
share/doc/rosemary/SOURCES.yaml.
